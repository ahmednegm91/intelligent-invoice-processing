# كل إضافات وتخصيصات العملاء | Client Customization & Optional Features

[الصفحة العربية الرئيسية](../README_AR.md) · [النسخة الإنجليزية الكاملة](customization-options.md) · [تحديد متطلبات العميل](client-requirements.md)

**مهم:** كل المميزات المذكورة هنا **اختيارات لتطويرات مستقبلية بناءً على طلب العميل**، وليست وظائف منفذة في النسخة التجريبية الحالية. أي ميزة تتطلب الاتفاق على النطاق والتكاملات والتكلفة والاختبارات ومتطلبات الخصوصية.

## 1. استقبال الفواتير والمستندات

- استقبال الفواتير تلقائيًا من Gmail وOutlook وMicrosoft 365 وIMAP.
- مراقبة Google Drive وOneDrive وSharePoint وSFTP والتخزين المؤسسي.
- استقبال ملفات عبر WhatsApp Business Platform والقنوات المصرح بها وفق شروط المزود.
- Webhooks وREST APIs وبوابات رفع آمنة للموردين والعملاء.
- Bulk Upload ومعالجة دفعات وإمكانية تقسيم PDF متعدد الفواتير، وفرز المستندات حسب النوع.

## 2. الذكاء الاصطناعي وOCR

- اختيار مزود AI بحسب العميل: Gemini أو OpenAI أو مزود آخر بواجهة مناسبة.
- استخدام نماذج OCR/AI تعمل داخليًا بالكامل، بعد تقييم دقتها على الفواتير العربية والإنجليزية وحجم الموارد المطلوبة.
- تحسين الصور الممسوحة ضوئيًا وتصحيح الميل والدوران واكتشاف جودة الملف.
- Structured Output Schema وفحص الحقول المطلوبة مع إظهار المصادر داخل الصفحات.
- تقييم درجة الثقة ونسب الخطأ على مجموعة فواتير مرجعية معتمدة.
- Provider-independent Fallback وقيود للتكلفة والـTimeout والـRetry.
- دعم قوالب الموردين المختلفة والعملات واللغات وصيغ التواريخ.

## 3. التحقق المالي والضريبي والاشتباه

- فحص VAT حسب قواعد بلد العميل، مع مراجعة متخصص بدل افتراض الامتثال التلقائي.
- التأكد من الخصومات والشحن والإضافات والبنود والمبالغ المكتوبة بالحروف.
- كشف الفواتير المتشابهة حتى مع اختلاف الأسماء أو الأرقام البسيط.
- مقارنة الموردين بقائمة الموردين المعتمدين وأرقام التسجيل الضريبي.
- مطابقة الفاتورة مع Purchase Order في نظام Two-Way Matching.
- مطابقة الفاتورة وأمر الشراء ومحضر الاستلام في Three-Way Matching.
- تنبيهات لتغيير الحساب البنكي أو المبالغ غير المعتادة أو بيانات ناقصة.

## 4. الموافقات البشرية والآلية والمراجعة الثانية

| الاختيار | طريقة العمل المقترحة |
|---|---|
| **Human Approval** | موظف مصرح له يراجع المستند، يصحح البيانات، ويوافق أو يرفض |
| **AI-Assisted Approval** | AI يقترح القرار والسبب، والقرار النهائي للموظف |
| **AI Approval** | موافقة آلية على حالات منخفضة المخاطر بشروط مالية واضحة، مع مسار استثناءات |
| **AI Approval + AI Reviewer** | نموذج ثاني مستقل يراجع قرار الأول ويكتشف التعارض ويطلب تصعيدًا عند الشك |
| **Hybrid Risk-Based Approval** | موافقات آلية للحالات المؤهلة ومراجعة بشرية للمبالغ العالية أو البيانات المتعارضة |

ويمكن إضافة Approval متعدد المستويات، صلاحيات حسب المبلغ، إشعارات وتأخير وتصعيد، سجل قرارات، وتفويض موظفين.

**ملاحظة جوهرية:** وجود AI Reviewer ثاني ممكن يحسن ضبط الجودة، لكنه **لا يضمن نسبة خطأ شبه صفر** لأن الموديلين ممكن يكرروا نفس الخطأ. أي نسبة دقة لازم تتقاس على حالات فعلية متنوعة ويُفضل الحفاظ على المراجعة البشرية للحالات المهمة.

## 5. ربط المحاسبة وERP

- QuickBooks وXero وOdoo وZoho Books والأنظمة الأخرى ذات API مناسب.
- SAP وDynamics 365 وNetSuite أو نظام محاسبي خاص بالعميل حسب الترخيص وإمكانات التكامل.
- إنشاء Draft Bill بدل ترحيل قيد بشكل نهائي قبل الموافقة.
- مزامنة الموردين ومراكز التكلفة والمشروعات وأوامر الشراء والحسابات.
- منع إرسال الفاتورة المحاسبية مرتين وتسجيل رقم العملية في ERP.

## 6. التخزين والأرشفة والبحث

- PostgreSQL وMySQL أو قاعدة بيانات يديرها العميل بدل Data Tables التجريبية.
- أرشفة أصل PDF/JPG/PNG في Cloud Storage أو مساحة خاصة أو سيرفر داخلي.
- سياسة احتفاظ ومسح وتشفير ونسخ احتياطي وبصمة ملف لتتبع النسخ.
- البحث بالمورد ورقم الفاتورة والتاريخ والمبلغ والحالة والمشروع.
- فصل الفروع والشركات والكيانات القانونية عن بعضها.

## 7. الإشعارات والتعاون

- Email وTeams وSlack وTelegram وWhatsApp Business المصرح به.
- تنبيه عند خطأ مالي أو استخراج فاشل أو فاتورة مكررة أو انتظار موافقة.
- تصعيد تلقائي للمسؤول وتأخير الموافقات والمهل الزمنية.
- تقارير يومية وأسبوعية وروابط للمراجعة وإعادة المحاولة.

## 8. التقارير وDashboards

- أعداد الفواتير حسب المورد أو المشروع أو الشهر أو الفرع.
- إجمالي المبالغ والعملات والحالات ونسبة الأخطاء والتكرار.
- زمن المعالجة وتكلفة AI والاستضافة والمراجعة البشرية.
- تقارير الذمم المستحقة وتواريخ الدفع والتأخير عندما تتوفر البيانات.
- تصدير Excel/CSV والتكامل مع Power BI أو لوحات خاصة.
- مؤشرات دقة حقيقية بعد مقارنة النتائج بتصحيح بشري موثق.

## 9. توسيع العمليات المالية

- متابعة مواعيد الاستحقاق وحالات الدفع والمطابقة مع التحويلات.
- Multi-Currency بمصدر معتمد لسعر الصرف وتاريخ المحاسبة.
- تصنيف GL Accounts والمصروفات ومراكز التكلفة والمشروعات.
- Credit Notes والفواتير الجزئية والمرفقات واتفاقات الدفع.

## 10. الأمن والحوكمة والخصوصية

- Authentication وRBAC وMFA/SSO حسب البيئة.
- تشفير النقل والتخزين، وإدارة مفاتيح API بأمان، وصلاحيات محدودة.
- Audit Logs لكل استخراج وتعديل وقرار وترحيل.
- سياسات الاحتفاظ والحذف والتدقيق وإقامة البيانات داخل دولة محددة عند الحاجة.
- فحص ملفات حقيقي ضد Malware والتأكد من Content Signature.
- مراجعة شروط مزود الذكاء الاصطناعي قبل إرسال فواتير تحتوي بيانات حساسة.

## 11. الاعتمادية والإنتاج والقدرة على التوسع

- Queue Processing وBatching والتحكم في التشغيل المتزامن.
- Transactional Unique Key وتسجيل منع التكرار بصورة مضمونة في قاعدة مناسبة.
- Retry / Backoff / Dead-letter Queue وMonitoring وتنبيهات.
- Backup/Restore وبيئات تجريبية وإنتاجية وRollback وتحديثات آمنة.
- مراقبة استهلاك API وتكاليفها وحدودها وجودة الموديلات بعد أي تحديث.

## 12. الاستضافة Cloud أو Client-Controlled أو On-Premises

| طريقة الاستضافة | المعنى |
|---|---|
| **Managed Cloud** | n8n وخدمات تخزين سحابية حسب خطة العميل، مع مزود AI معتمد |
| **Client-Controlled Cloud** | n8n والتخزين داخل حساب العميل السحابي وسياسته الأمنية |
| **On-Premises Hybrid** | n8n والبيانات المخزنة داخليًا مع إمكانية اتصال خارجي بمزود AI |
| **Fully Private Design** | n8n والتخزين وOCR/AI جميعها داخل بنية يسيطر عليها العميل، بعد تنفيذ وتقييم منفصلين |

**التخزين الداخلي وحده مش كفاية لاعتبار البيانات خاصة بالكامل** لو بنرسل مستندات إلى Gemini أو أي Cloud AI. الخصوصية الفعلية تعتمد على مسار البيانات كله، وليس مكان قاعدة البيانات فقط.

## 13. اللغة والفروع والهوية التجارية

- واجهات عربية RTL وإنجليزية ولوحات مراجعة بلغتين.
- دعم فواتير متعددة العملات والفروع والشركات والقوانين المحلية بعد ضبطها.
- تخصيص بوابة الموردين باسم وهوية العميل.
- قوالب مختلفة للحقول المطلوبة لكل قطاع أو بلد أو مورد.

## إزاي نبدأ مشروع خاص بشركة؟
